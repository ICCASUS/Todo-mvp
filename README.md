# 待辦事項 MVP

一個極簡的待辦事項網頁應用。整個專案只有一個 `index.html`，不需要安裝套件、不需要後端、不需要網路連線。

## 1. 專案解決什麼問題

日常需要快速記下幾件待辦事項時，多數工具都太重：要註冊帳號、要安裝 App、功能多到找不到重點。

這個專案提供最小可用的替代方案：

- 打開一個 HTML 檔就能用，零安裝、零設定
- 資料存在自己的瀏覽器裡，不上傳到任何伺服器
- 只有「新增、完成、刪除」三個動作，沒有學習成本

它適合當作個人隨手筆記、或作為前端待辦事項應用的最小範例。

## 2. 主要功能

| 功能 | 說明 |
| --- | --- |
| 新增待辦 | 在輸入框輸入文字後按 Enter 或點「新增」。前後空白會自動去除，空白內容不會新增。單筆上限 200 字。 |
| 標記完成 | 勾選項目前的方框，文字加上刪除線並變灰；再點一次可取消完成。 |
| 刪除待辦 | 點項目右側的 ✕，該項目立即移除。 |
| 剩餘計數 | 清單底部顯示「剩餘 N 項 / 共 M 項」，清單為空時不顯示。 |
| 空清單提示 | 沒有任何項目時顯示「目前沒有待辦事項」。 |
| 自動儲存 | 每次操作後立即寫入瀏覽器 localStorage，重新整理或關閉再開啟都會保留。 |

目前**不包含**的功能：編輯既有項目文字、拖曳排序、篩選（全部 / 未完成 / 已完成）、多裝置同步、到期日與提醒。

## 3. 安裝方法

無需安裝任何東西，只要有現代瀏覽器（Chrome、Edge、Firefox、Safari 皆可）。

取得檔案：

```bash
git clone <此專案的 repository 網址>
cd todo-mvp
```

或直接下載 `index.html` 單一檔案即可。

## 4. 使用方法

### 方法一：直接開啟檔案

在檔案總管中對 `index.html` 點兩下，或在專案目錄執行：

```bash
start index.html
```

（macOS 用 `open index.html`，Linux 用 `xdg-open index.html`。）

### 方法二：透過本機靜態伺服器

若你希望以 `http://` 而非 `file://` 開啟，可用 Python 內建伺服器：

```bash
python -m http.server 8000
```

然後在瀏覽器開啟 <http://localhost:8000>。

### 操作步驟

1. 在輸入框輸入待辦內容，按 Enter 或點「新增」。
2. 完成後勾選前面的方框。
3. 不需要的項目點右側 ✕ 刪除。

### 清除所有資料

資料存在瀏覽器 localStorage 的 `todo-mvp` 這個 key 底下。想清空全部項目，可在瀏覽器開發者工具的 Console 執行：

```js
localStorage.removeItem('todo-mvp'); location.reload();
```

> 注意：localStorage 是以「網址來源」區分的。用 `file://` 開啟和用 `http://localhost:8000` 開啟，看到的會是兩份獨立的資料。

## 5. 輸入輸出範例

### 畫面操作

| 步驟 | 輸入 | 畫面輸出 |
| --- | --- | --- |
| 初始狀態 | 第一次開啟 | 清單為空，顯示「目前沒有待辦事項」，底部無計數 |
| 新增 | 輸入「買牛奶」後按 Enter | 清單出現「買牛奶」；底部顯示「剩餘 1 項 / 共 1 項」；輸入框清空並保持焦點 |
| 再新增 | 輸入「寫報告」後點「新增」 | 清單依序顯示「買牛奶」「寫報告」；底部顯示「剩餘 2 項 / 共 2 項」 |
| 新增空白 | 輸入三個空格後按 Enter | 沒有任何變化，不會新增項目 |
| 完成 | 勾選「買牛奶」 | 「買牛奶」加上刪除線並變灰；底部顯示「剩餘 1 項 / 共 2 項」 |
| 取消完成 | 再點一次「買牛奶」的方框 | 刪除線消失；底部顯示「剩餘 2 項 / 共 2 項」 |
| 刪除 | 點「寫報告」右側的 ✕ | 「寫報告」消失；底部顯示「剩餘 1 項 / 共 1 項」 |
| 全部刪除 | 點「買牛奶」右側的 ✕ | 清單為空，顯示「目前沒有待辦事項」，底部無計數 |

### 儲存資料格式

localStorage 中 `todo-mvp` 這個 key 的值是一個 JSON 陣列，每筆項目有三個欄位：

| 欄位 | 型別 | 說明 |
| --- | --- | --- |
| `id` | number | 建立當下的時間戳（毫秒），作為唯一識別 |
| `text` | string | 待辦文字，已去除前後空白 |
| `done` | boolean | 是否已完成 |

以上表格操作到「完成」那一步時，儲存的內容為：

```json
[
  { "id": 1789522626886, "text": "買牛奶", "done": true },
  { "id": 1789522630120, "text": "寫報告", "done": false }
]
```
